## 使用说明

### 基本功能
- 桌面宠物支持显示GIF/BMP/JPG/PNG图像
- 支持拖动宠物到任意位置
- 双击宠物可隐藏，通过系统托盘可再次显示
- 全局热键 Ctrl+Alt+P 可快速显示/隐藏宠物

### 特色功能
- 整点报时：在整点时提醒您当前时间
- 自定义图像：可以选择自己喜欢的图片作为宠物
- 透明度调节：可以调整宠物的透明度
- 快捷键设置：可以设置F1-F12+字母键的组合快捷键
